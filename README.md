# Nicht Website

A moody first-person puzzle adventure marketing hub. Built with Jekyll and hosted on GitHub Pages.

## Structure

- `index.html` — Landing page
- `chapter-1.html` — Chapter 1 detailed page
- `roadmap.html` — Game roadmap
- `devlog/` — Development blog
- `press.html` — Press kit
- `css/style.css` — Design system & stylesheet
- `_config.yml` — Jekyll configuration

## Design System

**Colors:**
- Base: `#0a0a0a` (near-black)
- Accent: `#c41e3a` (anger-red)

**Typography:**
- Serif: Georgia, Garamond
- Sans: System fonts

**Mood:**
- Restrained, emotional, deliberate
- Subtle film-grain texture
- Minimal motion

## Local Development

To view locally:

```bash
cd c:\Projects\NichtWebsite
jekyll serve
```

Then open `http://localhost:4000` in your browser.

## Deployment

Push to GitHub to deploy via GitHub Pages.
